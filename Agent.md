# AGENTS.md

## Project Overview

This repository supports a collaborative literature review project on:

# High-Level Semantic Driven Virtual Human Crowd Simulation

The goal of this project is to investigate how high-level semantic information
(e.g., language, goals, social context, environmental understanding, and world knowledge)
can drive the generation, control, and simulation of virtual human crowds.

The review focuses on the intersection of:

- Crowd simulation
- Virtual humans
- Multi-agent systems
- Large Language Models (LLMs)
- Generative AI
- Semantic scene understanding
- Procedural population generation
- Behavior generation
- Agent-based simulation


---

# Role of the Agent

The agent acts as a:

- Research assistant
- Literature organizer
- Knowledge base maintainer
- Writing assistant

The agent MUST NOT:

- Invent experimental results
- Fabricate citations
- Replace researchers' critical judgement
- Generate unsupported scientific claims
- Decide the final structure of the paper without discussion


The agent SHOULD:

- Maintain repository consistency
- Help summarize papers
- Identify connections between works
- Suggest possible taxonomy structures
- Track research gaps
- Assist with writing and editing


---

# Research Theme

## Main Research Question

How can high-level semantic information enable more realistic,
controllable, and scalable virtual human crowd simulation?


## Key Questions

The review should answer:

1. How have traditional crowd simulations represented human behavior?

2. What limitations exist in rule-based and data-driven approaches?

3. How can LLMs and generative models provide semantic-level control?

4. How can individual agents generate emergent crowd behaviors?

5. What challenges remain for realistic virtual world population?


---

# Literature Organization Principle

Each paper should be classified according to:

## 1. Semantic Input Level

Examples:

- Low-level:
    - trajectories
    - velocity
    - motion primitives

- Mid-level:
    - activities
    - navigation goals
    - interaction rules

- High-level:
    - natural language
    - social intention
    - environmental context
    - world knowledge


## 2. Generation Mechanism

Possible categories:

- Rule-based simulation

- Data-driven learning

- Neural behavior generation

- Generative models

- LLM-based agents

- Multi-agent systems


## 3. Simulation Target

Examples:

- Individual virtual humans

- Small groups

- Dense crowds

- Large-scale virtual worlds

- Urban environments
