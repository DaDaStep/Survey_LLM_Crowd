# Meetings

This folder holds the team's meeting notes. One file per meeting, named
`YYYY-MM-DD-<topic>.md`.

---

## Conventions

- File name: `YYYY-MM-DD-<kebab-case-topic>.md`.
- Use the structure from the **Meeting note** issue template
  (`.github/ISSUE_TEMPLATE/meeting-note.md`).
- Decisions must be **actionable**: each one should reference the roadmap
  item it changes, or open a new one.
- Action items must have an owner and a due date.
- Anyone who missed the meeting reads top-to-bottom and objects in the PR /
  issue thread within 48 hours if they disagree.
